# Conversation Feedback Rubric

Check:

- feedback preserves learner meaning;
- at most the allowed number of corrections is given;
- the selected issue matches priority rules;
- the explanation fits the learner's level;
- a better expression is usable in the current scenario;
- uncertain pronunciation is not diagnosed from text alone;
- praise names a specific successful behavior;
- the learner gets a chance to try again;
- candidate memory includes evidence and confidence;
- optional naturalness is not presented as categorical wrongness.
