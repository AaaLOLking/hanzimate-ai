# Week 4 验收清单

> 范围：场景目录、实时连接恢复、预算保护和可审计可靠性事件。

## 自动验收

- [x] 提供食堂、便利店、问路、宿舍、医院、课堂 6 个场景模板；
- [x] 场景切换会更新工作区标题、唯一目标、开场语和提示句；
- [x] 医院场景明确限制为语言教学，不提供诊断或治疗建议；
- [x] VoiceSession 支持 `reconnecting → active`，同一会话可重新交换 SDP；
- [x] 浏览器断线后最多自动重连 2 次，并把最近 6 轮转写重新注入恢复上下文；
- [x] 重连失败或 Provider 报错后保留会话写入能力，自动降级为文字与本地朗读；
- [x] 连接、断线、重连、打断、首响应、预算警告和降级事件按 `client_event_id` 幂等保存；
- [x] 可靠性事件和聚合指标强制按用户隔离；
- [x] 8 分钟上限前 60 秒显示预算提醒，到时自动结束，后端再次裁剪超长时长；
- [x] 结束后刷新可恢复场景、时长和完整转写。

## 验收证据

- API：16 个 pytest 用例通过，新增覆盖 6 场景、事件幂等、用户隔离、时长裁剪、重新交换 SDP 和失败降级；
- 数据库：迁移 `0001 → 0002 → 0003` 成功，`alembic check` 无漂移；
- Web：ESLint、TypeScript 与 Next.js 生产构建通过；
- 浏览器：选择“医院挂号”后正确显示安全边界；会话创建 201、2 条可靠性事件 201、3 条转写 201、结束 200；
- 恢复：刷新后恢复 29 秒会话和 3 条转写；浏览器控制台 0 error / 0 warning；
- 截图：`output/playwright/week-04/week-04-live-reliability.png`（本地产物，不进入版本控制）。

## 真实 Provider 边界

当前环境仍未配置 DashScope API Key 与 Workspace ID，所以自动重连逻辑只完成了 Provider 合同与浏览器状态机实现；真实 Qwen 链路的 8 分钟稳定性、断网恢复、打断延迟和实际成本仍需凭证测试。Mock 验收不能替代这些数据。
