# Week 9 验收记录

范围：个人学习档案、数据导出与删除、AI 调用记录与用量保护，以及基础键盘和手机可用性。

## 必须满足

- [x] 用户可查看目标、能力自评、课程、对话、错误记忆和复习的真实统计。
- [x] 个人数据可下载为 JSON，内容只属于当前用户，不包含密钥或课程内部答案规则。
- [x] 删除账户必须同时匹配当前邮箱和固定确认语，并清除关联学习记录。
- [x] 已确认的错误记忆可由本人修改或归档，其他用户无法读取或改写。
- [x] 课程答疑与对话总结保存来源、模型、耗时、估算用量、成功、失败和保护状态。
- [x] 每日外部调用次数和估算费用都可设上限；触发保护或服务失败后自动使用本机规则。
- [x] 没有填写模型价格时不展示误导性的费用数字，仍启用调用次数保护。
- [x] 未配置 DeepSeek 凭证时，界面只把本机规则显示为可用文本模型，不冒充在线模型。
- [x] 原始录音在当前 MVP 中不保存；旧同意记录也明确显示“当前版本仍未保存”。
- [x] 每页有清楚的标题、键盘跳转入口和明显焦点；减少动态效果设置得到尊重。

- 数据升级：本机从 `20260831_0006` 升级至 `20260902_0007`，结构检查无差异；升级前备份为 `apps/api/data/backups/before-week09-20260902.sqlite3`。
- Web：ESLint、TypeScript 和 Next.js 生产构建通过，新增 `/profile` 页面。
- 真实浏览器：学习档案显示临时用户真实数据和本机 AI 记录；数据文件成功下载；删除按钮在邮箱和确认语都匹配前保持不可用。

## 当前边界

- 费用是按后台填写的单价和估算用量计算，不等同于供应商最终账单；未填写单价时不展示费用。
- 当前次数与费用保护适用于课程答疑和对话总结；实时语音仍使用既有时长上限和会话事件记录。
- 删除回执只保留随机编号、删除时间和各类记录数量，不保留账户编号或邮箱。
- 正式身份登录、公网上线、告警通知和多浏览器实验室测试留到 Week 10 上线准备。
