# Week 8 验收记录

范围：确认错误 → 定期复习 → 作答反馈 → 用户自评 → 下次安排，以及个人偏好和站内提醒。

## 必须满足

- [x] 只有已确认活跃记忆进入复习，旧记忆自动补建，归档停止调度。
- [x] 作答前不下发参考答案；提交后可刷新恢复待自评状态。
- [x] 四种用户自评进入真实 FSRS，规则检查不覆盖用户选择。
- [x] 自定义 1–60 天间隔、学习日、时区和复习密度可保存。
- [x] 保存不可变日志、前后状态、参数与实际日期，支持重放。
- [x] 重试不重复计数，旧版本不能重复自评，其他用户不能访问。
- [x] 站内提醒主动开启，每天最多一次，尊重当地日期、时间与学习日。
- [x] 首页复习数量和错误示例来自真实记录，不使用虚构掌握百分比。
