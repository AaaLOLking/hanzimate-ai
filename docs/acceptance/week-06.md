# Week 6 验收清单

> 范围：首个课程纵向切片，包括版本化课件、三阶段练习、学习证据、进度恢复与课内 AI 导师。

## 自动验收

- [x] 课程目录提供 1 个不可变课程版本与 3 节可运行短课；
- [x] 每课满足单一目标、5–20 分钟、至少 2 个例子、引导/检索/迁移三阶段和来源合同；
- [x] 已发布课件正文、评分规则、课程身份或课节集合变化都会被版本锁拒绝；
- [x] 浏览器不接收 `answer_rule` 或 `assessment_config`；
- [x] 开始课程幂等创建唯一 `LessonProgress + Workspace`，刷新后恢复步骤、证据和聊天；
- [x] 服务端强制引导 → 检索 → 迁移顺序，失败尝试也会留下不可覆盖的学习证据；
- [x] 只有迁移任务通过才完成课程和 workspace，不能用浏览到底冒充完成；
- [x] 课内导师只使用当前课节 Context Pack、最多 3 条相关 active 记忆和最近 6 条本课消息；
- [x] 课程进度、消息、错误记忆和作答 API 均按用户隔离；
- [x] DeepSeek Key 仅留在后端；无凭证或失败时明确降级到 `local / lesson-context-v1`。

## 验收证据

- API：27 个 pytest 用例通过，其中 6 个课程用例覆盖目录合同、版本锁、幂等开始、失败重试/完成证据、课内消息、跨用户隔离和 DeepSeek 请求合同；
- 数据库：全新 SQLite 从 `0001 → 0005` 成功，`alembic check` 无漂移；本地已有表只在只读结构与空学习数据确认后对齐版本号；
- 教学 Skill：`validate_skill_assets.py` 通过，课件设计遵循 Mission 对齐、检索优先、即时反馈和证据完成；
- Web：ESLint、TypeScript 与 Next.js 生产构建通过，新增 `/courses` 与 `/lessons/{lessonId}`；
- 浏览器：本地完成“目录 → 开始量词课 → 课内提问 → 首次作答失败 → 改正 → 无提示检索 → 刷新恢复 → 迁移完成 → 目录显示 1/3”全链路；
- 运行质量：浏览器控制台 0 error / 0 warning，17 个课程业务请求全部返回 2xx；
- 截图：`output/playwright/week-06/week-06-course-catalog.png`、`week-06-lesson-complete.png`、`week-06-course-progress.png`（本地产物，不进入版本控制）。
