# 信息架构与界面基线

## 1. 导航原则

- 左侧回答“我在哪里、还能去哪里”；
- 中间回答“我现在要完成什么”；
- 右侧回答“AI 当前知道什么、我能问什么”；
- 同一 workspace 内不切换学习目标；
- 错误反馈必须能回到原始证据。

## 2. 一级导航

| 导航 | 默认内容 | 关键操作 |
|---|---|---|
| 今日 | 到期复习、推荐课程、连续学习 | 开始今日计划 |
| 对话训练 | 场景、历史会话、自由对话 | 新建对话 |
| 系统课程 | 课程路径、章节、进度 | 继续学习 |
| 错误回顾 | 错误簿、到期队列、趋势 | 开始复习 |
| 学习档案 | Mission、能力、AI 记忆、隐私 | 编辑或删除 |
| 设置 | 模型、语速、辅助语言、提醒 | 保存偏好 |

布局宽度建议：

- 左侧 240–280 px，可收起；
- 右侧 320–380 px，可隐藏；
- 中间最小 640 px；
- 小于 1024 px 时右栏变抽屉；
- 小于 768 px 时左栏变底部导航。

## 5. 页面状态

### 实时对话

- idle：展示任务和麦克风检查；
- connecting：明确正在连接，不允许重复点击；
- listening：突出用户正在说话；
- thinking：保留转写，不伪造进度；
- speaking：展示可打断提示；
- reconnecting：本地保留已完成轮次；
- ended：立即展示基础统计，异步补全报告；
- failed：提供文本继续或重新连接。

### 会话报告

- processing：展示已保存转写和报告任务状态；
- ready：亮点、重点错误、场景完成度、下一步；
- reviewed：用户已确认/驳回所有候选；
- stale：Skill 或课程规则更新，但保留原报告版本。

### 课程

- not_started；
- in_progress：依次完成引导、检索和迁移任务；
- completed：迁移任务已产生通过证据；
- review_due：课程级复习待后续建设；Week 8 仅调度已确认错误。

课程目录只展示每门课程最新的已发布版本，并按“生活与校园沟通 / HSK 能力训练”分组。历史 Workspace 继续打开其原始课节版本，不自动迁移证据。

### 错误复习（Week 8）

`/reviews` 左侧为到期/今日已复习统计，中间依次显示题目、作答反馈、自评与下一次日期，右侧保存个人节奏。刷新恢复同一待自评作答。首页显示真实到期数据，不显示虚构掌握率。站内提醒由用户主动开启；没有到期内容时提供课程或错误本入口。

## 7. 视觉基线

- 使用温暖的纸张色替代纯白，避免工具感过强；
- 导航保持中性深色，学习状态使用绿色和琥珀色；
- 用户语音与 AI 语音不使用过多气泡，优先时间线排版；
- 每屏最多一个主行动按钮；
- 拼音、汉字、英文解释形成清晰三级层次；
- 纠错先显示“更自然的表达”，再展开语法术语；
- 不用红色覆盖整张错误卡，红色只表示阻断性问题。

## 8. 原型验收

- 用户不看说明也能从今日页开始第一次对话；
- 麦克风、AI 是否正在说、能否打断始终可见；
- 任一错误在两步内能看到证据；
- 任一长期记忆在三步内可删除；
- 课程提问不会遮住核心练习；
- 1366×768 分辨率下三栏仍可使用。
