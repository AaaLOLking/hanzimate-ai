# HSK 考纲与资料整理策略建议（讨论稿）

日期：2026-09-18。状态：待用户决策，非已定设计。

问题：HSK 考纲、词汇、语法点等资料，用「联网搜索实时检索」还是「自建知识库」？参照 CSCA-agent（`D:\和claude有关的所有子项目\csca agent\CSCA-agent`）的实装做法给出建议。

## 1. 先说结论

**知识库为主，联网搜索兜底。** 这也是 CSCA-agent 实际采用的架构。

理由一句话：HSK 考纲是**静态、有边界、强结构化**的数据——词汇表、语法点表、题型结构，一年几乎不变——这正是知识库的最佳适用场景；而联网搜索的长处是「新鲜、开放、无边界」的信息，与考纲资料的特性完全相反。

## 2. CSCA-agent 的参照架构（实测提取）

CSCA-agent 面对一模一样的问题（CSCA 留学学业测试的数学/物理/化学考纲与题库），它的答案是：

```
官方 PDF（题库/大纲/ 目录下的 CSCA * Syllabus-2025.pdf）
  → data/cleaned_markdown/*.txt        （清洗后的文本）
  → data/processed/*.json              （结构化题库：csca_questions_v1.json 等）
  → data/syllabus.json                 （知识图谱：学科→模块→主题，含难度与父子关系）
```

- **离线管线脚本**：`scripts/clean_markdown.py`、`build_json.py`、`build_unified_bank.py`，配**审计脚本** `audit-question-bank.mjs`、`audit-cross-source.mjs`（跨来源核对，防脏数据入库）
- **运行时读取层**：`lib/csca/syllabus.ts`、`knowledge-data.ts`、`question-bank.ts`
- **RAG 检索**：`lib/rag/retriever.ts` 目前就是**关键词匹配的 mock**，向量库（Pinecone）只是预留的 production 选项——说明结构化数据 + 简单检索已经够用，向量库不是第一天必需品
- **联网搜索**：`lib/web-search/` 四个适配器（baidu/bocha/brave/tavily）做成**独立补充能力**，不用于回答考纲问题

## 3. 为什么知识库适合 HanziMate 的 HSK 场景

| 维度 | 知识库 | 联网搜索（Tavily 等） |
|---|---|---|
| 准确性 | 人工审校入库，等级/来源确定 | SEO 内容农场混杂，HSK 2.0（六级）与 3.0（九级）经常互相污染 |
| 延迟 | 本地毫秒级 | 1–3 秒 + 结果解析——**语音对话中不可接受** |
| 成本 | 入库后零边际成本 | 每次调用计费 |
| 可审计 | 每条数据带来源与版本 | 结果不可复现 |
| 覆盖面 | 入库范围内完整 | 考纲外问题（如「HSK 考场在哪」）也能答 |

语音实时场景是关键放大器：用户在通话中问「把字句是 HSK 几级」，等 3 秒搜索 + 解析会破坏对话节奏；本地检索无感。

## 4. 落地建议（HanziMate 版）

### 4.1 数据层：离线管线，参考 CSCA 脚本结构

- 数据源优先级：官方《HSK 考试大纲》（中外语言交流合作中心）＞ 官方真题/样题 ＞ 权威辅导资料。注意版权：大纲事实性数据（词表、语法点列表）可用，原文例句注意不要整本复制
- **版本锚点（2026-09-18 调研更新）**：HSK 3.0 已于 **2026-07-01 全面生效**（2025-11 汉考国际发布修订版大纲，一级词汇下调至 300 词等），知识库应**以 3.0 九级体系为主体**。但 2.0 六级标签仍被大量存量资料与学习者沿用，词条应做双等级标注（参照 drkameleon/complete-hsk-vocabulary 的 `"level": ["new-1", "old-3"]` 格式）。元数据记 `version`/`lastUpdated`（CSCA 的 syllabus.json 同习惯）
- 存储：起步用版本化 JSON 文件（与现有 `course_catalog_v2.json` 同模式，可 diff、可审计）；数据量上来或需要组合查询时再迁 SQLite 表
- 建议 schema 雏形：
  ```json
  {
    "metadata": {"standard": "HSK2.0", "version": "...", "sources": [...]},
    "vocabulary": [{"word": "把", "pinyin": "bǎ", "pos": "prep", "level": 3, "example": "..."}],
    "grammar": [{"point": "把字句", "level": 3, "structure": "...", "examples": [...], "related": [...]}],
    "exam_format": [...]
  }
  ```

### 4.2 检索层：先简单，后按需升级

- 第一阶段：结构化精确检索（按词/语法点/等级/拼音），就是现在 `hsk_lookup` 的加强版——CSCA 至今也只用了关键词匹配
- 第二阶段（可选）：如果发现学习者提问经常「绕弯」（如「表示‘不得不’的句型」），再引入向量检索（本地 embedding 即可，不必上 Pinecone）
- 保留现有约定：检索结果带来源标识；查不到就明说，不编造

### 4.3 工具分工（与现有架构对齐）

- `hsk_lookup` → 升级为查 HSK 知识库（考纲权威答案，毫秒级，语音中可用）
- `web_search` → 保持兜底定位：考纲外、时效性问题（考试时间、报名、考点变化），回答必须带「需自行核实来源」标记（现有设计已如此）
- 语音会话内模型优先走 `hsk_lookup`；`web_search` 可以在系统提示里引导为「学员明确要求查最新信息时才用」

### 4.4 管线质量

照抄 CSCA 的两个好习惯：
- **审计脚本**：入库后跑交叉核对（同一词汇在不同来源的等级是否一致、JSON schema 校验、重复条目检查）
- **provenance**：每条数据记来源文件与页码/章节，便于日后核对与纠错

## 5. 值得纳入的资料清单（2026-09-18 调研）

### 第一梯队：官方骨架（必纳入）

1. **新版《HSK考试大纲》**（语合中心/汉考国际，2025-11 修订、2026-07 全面生效）——含任务大纲、话题大纲、词汇大纲、汉字大纲、语法大纲（一至九级），词汇大纲带拼音词性。PDF：`https://hsk.cn-bj.ufileos.com/3.0/新版HSK考试大纲1219.pdf`
2. **《国际中文教育中文水平等级标准》GF0025-2021**（教育部/国家语委，2021）——三等九级框架与四项量化指标（音节/汉字/词汇/语法累计数），可做等级自检表。教育部官网有完整 PDF（约 260 页）。
3. **各等级官方大纲 PDF**（chinesetest.cn 下载区，如 `download.chinesetest.cn/newhsk-site/Syllabus/H1_DG.pdf`）。
4. **HSKK 口语考试官方大纲与样卷**（`chinesetest.cn/userfiles/file/dagang/HSK-koushi.pdf`）——**对语音产品尤其重要**：初/中/高级题型（听后重复、看图说话、听后复述、朗读、回答问题）可直接映射为我们的语音练习任务模式。

### 第二梯队：结构化数据种子（加速入库）

5. **GitHub `drkameleon/complete-hsk-vocabulary`**：`complete.json` 全词条（2.0+3.0 双等级标注、拼音、词性、部首、词频），带 LICENSE 与自动更新 workflow。作词汇层种子，入库时与官方大纲交叉核对（CSCA 的 audit-cross-source 思路）。
6. **`clem109/hsk-vocabulary`**：词条带例句，可补例句层。

### 第三梯队：教学与练习素材

7. **《HSK标准教程》**（北京语言大学出版社 × 汉考国际，姜丽萍主编，1–6 级共 9 册）——官方授权、以真题为素材；作课程对齐参照，不整本入库（版权）。
8. **官方真题集/样题**（《HSK真题集》《HSKK真题集》，高教社）——题型结构入库，真题原文不入库（版权），存「题型→能力→示例」映射。
9. **话题/任务大纲单列一层**：直接喂养对话练习的场景选题，与现有 scenario/free/custom 模式对齐。

### 明确不纳入

- 网上流传的未署名词汇表（版本混乱，2.0/3.0 混杂）
- 整本教材原文、真题原文（版权）
- 培训机构「押题/内部资料」（质量与版权双风险）

## 6. 分期路线建议

1. **第一期（最小可用）**：以 drkameleon 的 complete.json 为词汇种子，交叉核对官方大纲后入库；HSK 1–4 级词汇 + 高频语法点（约 100 个），hsk_lookup 切到知识库，检索质量人工抽查 50 条
2. **第二期**：5–6 级与 7–9 级词汇、题型结构说明、HSKK 口语任务模式映射、与课程 catalog 的双向链接（课程例句 ↔ 考纲语法点）
3. **第三期（可选）**：向量检索、错题本联动（学习者错的知识点自动标等级）

## 7. 知识库的教学使用方式（与现有架构对齐）

知识库进库后，agent 在四条链路上使用它教学：

### 8.1 实时语音链路（轻量、毫秒级，已在管道内）

- **答疑升级**：现有 `hsk_lookup` 工具换数据源——学员问「把字句怎么用/是几级」，返回考纲等级、结构、官方例句与来源；agent 不再「估计」等级，每个等级宣称都有据可查。
- **指令注入（用词难度护栏）**：会话开始/续接时把「学员估计等级 + 本次目标语法点/词汇范围」写进实时指令，agent 自我约束用词难度（i+1 输入假说的具体化：以学员等级词汇为主体，刻意引入下一级目标项）。
- 边界：实时链路只做轻查询，重检索/生成不放进来（延迟纪律）。

### 8.2 异步链路（DeepSeek 提供商，报告与复习）

- **会话报告等级化**：错误不再只是孤立记录，而是标注考纲语法点+等级（「把字句（HSK3 级）」）；报告建议下一步等级目标。
- **错误本/定期复习按考纲组织**：复习调度可以按等级与掌握度排列，学员看到「HSK2 的语法点你已掌握 80%」。
- **学习档案**：等级词汇覆盖率可视化。

### 8.3 练习生成

- **话题/任务大纲 → 对话场景**：考纲的话题大纲直接喂养 scenario/free/custom 的选题与目标模板（「HSK3 任务：租房」），练习内容天然对齐考试能力要求。
- **HSKK 题型 → 语音练习模式**：听后重复、看图说话、听后复述、朗读、回答问题——这些题型与我们语音通话形态天然同构，可做「口语考试模式」。
- **测验**：按等级从词表/语法点抽题。

### 8.4 水平评估（辅助、概率性）

- 学员在对话中主动使用的词汇/语法点的等级分布，作为水平估计的客观证据之一（现有 `estimated_hsk_band` 的数据支撑）。
- 边界：这是概率性参考，不做「你已通过 HSK3」式硬性定级宣称。

### 两层不混的原则

知识库回答「**教什么、对不对**」（考纲事实），教学 Skill（chinese-learning-coach）回答「**怎么教**」（教学法：纠错模式、语速、耐心、脚手架）——考纲数据进知识库，教学策略仍留在 Skill 里，两者通过「等级+目标点」这个接口对接。另外，默认不把语音教练变成刷题机：备考/刷题模式应由学员显式选择。

## 8. 风险与边界

- 官方大纲 PDF 的获取与解析是主要工作量（CSCA 的 cleaned_markdown 说明他们也走了这条路）
- HSK 3.0 改革推进中，等级体系可能变化——元数据版本字段是刚需
- 知识库有维护成本：每次官方更新需要重跑管线 + 审计
- 不把知识库内容当题库背题工具：它服务的是「教学答疑准确」，不是押题
