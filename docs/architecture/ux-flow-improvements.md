# UX 流程改进计划（对话训练入口 / 结束后回顾 / 语言切换）

日期：2026-09-20。状态：待用户确认三个决策点后开工。来源：用户真人体验反馈。

## 背景（代码现状核实）

1. **「对话训练」导航不可点击**：`apps/web/lib/navigation.ts` 中该项 `href: null`——旧首页硬编码导航的遗留，重构时原样保留进了共享 AppShell，成为全站死项。
2. **结束后流程**：结束并保存 → finalize → 自动生成学习报告 + 候选错误（`status="candidate"`）写入错误本 → 工作区置为 `review_due`。用户确认机制已存在但**在错误本页面里**（逐条确认/驳回），结束当下没有回顾与同意步骤；错误本按「聚类/候选」组织，**无日期维度**。
3. **无 i18n 基础设施**：全站中文硬编码，无语言切换。

## 项目 1：对话训练入口

- navigation.ts 的 `对话训练` 指向新页面 `/practice`（新建）。
- `/practice` 页：三种练习方式的卡片（场景练习 / 自由对话 / 自定义目标），沿用首页既有模式选择逻辑迁入；场景列表来自后端 voice_scenarios。
- 首页的「开始对话」入口改为跳 `/practice`（或保留原入口兼做快捷开始，迁移时按代码实际最小改动处理）。
- 验收：点击侧栏「对话训练」进入选模式页；三条路径都能发起会话；lint/typecheck/build + 浏览器截图核对。

## 项目 2：结束后回顾与错误本日期化

- 结束流程插入「本次回顾」步骤（报告生成后展示）：报告要点（笔记）+ 候选错误列表，**逐条勾选收入/忽略**后提交——提交调用现有 `PATCH /errors/{id}`（confirmed/rejected），不改后端合同。
- 笔记：沿用现有报告（要点 + 下一步建议）+ 转写 Markdown 导出入口。
- 错误本页面：新增**按日期分组视图**（按错误发生日期/会话日期分组展示事件，含所属聚类与状态）；保留现有聚类视图可切换。
- 验收：结束会话 → 回顾页勾选 → 错误本日期视图中按日出现；未勾选的标记 rejected 不再出现；后端全量回归不破（无 API 合同变更，只读/复用现有端点）。

## 项目 3：语言切换（中文 / English）

- 零依赖轻量 i18n：React Context + zh/en 字典文件（`apps/web/lib/i18n/`），切换器放侧栏底部（AppShell），首页同步生效。
- 范围（MVP）：AppShell 导航 + 首页全部文案 + /practice 页。其余页面保持中文，后续批次扩展。
- 用户语言选择持久化（localStorage；如需跨设备同步再入后端档案，本批不做）。
- 验收：切换后导航/首页/practice 全英文且无布局溢出；切回中文无残留；lint/typecheck/build 绿。

## 流程与约束（沿用老规矩）

- 单代理顺序实施（三个项目同一前端范围，不适合并行）；检查点 `.agent/ux-progress.md`；主空间核验。
- 不改后端 API 合同（如确需后端配合先报告）；无新依赖；不 git commit；实施前读 `apps/web/node_modules/next/dist/docs/`。
- 验证：lint/typecheck/build、CJS 19 项、后端 pytest 115 回归、Playwright 截图核对（三项目各自关键路径）、通话页 probe 四场景复跑（确认通话页未被影响）。
