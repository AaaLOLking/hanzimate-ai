# 宿舍报修时说清哪里坏了

> Generated public Wiki page. Assessment answers are intentionally omitted.

- Course version: 2
- Lesson version: 1
- Track: daily-life
- Framework / level: hsk-3.0 / HSK2–3
- Estimated time: 10 minutes

## Objective

宿舍报修时说出物品、具体问题，并提出一个礼貌的处理请求。

## Targets

报修, 坏了, 不能, 没有, 礼貌请求

## Explanation

报修要让对方快速知道三件事：什么东西、出现什么问题、希望对方做什么。可以用“物品 + 坏了/不能用了/没有……”说明问题，再用“麻烦帮我看看”提出请求。

## Examples

- **宿舍的空调坏了，不能制冷。** — 先说物品，再说可观察的问题。
- **洗衣机不能用了，麻烦帮我看看。** — 请求简短、礼貌，并且不替维修人员判断原因。

## Practice prompts

### Guided production

台灯坏了，不能开。请向宿管说清问题并礼貌报修。

### Unaided retrieval

不看例子：洗衣机不能用了。请用一句话完成报修。

### Transfer

新场景：宿舍淋浴没有热水。请给维修人员发一条完整、礼貌的信息。
