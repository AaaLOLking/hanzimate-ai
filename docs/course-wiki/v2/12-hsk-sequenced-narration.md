# 用“先、然后、最后”完成短叙述

> Generated public Wiki page. Assessment answers are intentionally omitted.

- Course version: 2
- Lesson version: 1
- Track: hsk
- Framework / level: hsk-3.0 / HSK4
- Estimated time: 12 minutes

## Objective

把三个给定信息按时间顺序组织成包含“先、然后、最后”的三步短叙述。

## Targets

短文组织, 先, 然后, 最后, 时间顺序

## Explanation

短叙述先确定事件顺序，再用连接词把句子组织起来。“先”标记第一步，“然后”推进中间事件，“最后”给出结尾或结果。连接词后仍要有完整动作。

## Examples

- **我先查了路线，然后坐地铁去学校，最后按时到了教室。** — 三个连接词对应三个按时间发生的动作。
- **她先复习生词，然后做练习，最后检查答案。** — 每一步都服务于同一个学习任务。

## Practice prompts

### Guided production

按顺序组织：查路线 → 坐地铁 → 到教室。必须使用“先、然后、最后”。

### Unaided retrieval

不看例子，组织学习过程：复习生词 → 做练习 → 检查答案。

### Transfer

新场景：描述第一次去校医院的过程：网上预约 → 到前台登记 → 见到医生。只描述流程，不提供医疗建议。
