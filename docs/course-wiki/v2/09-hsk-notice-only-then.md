# 从通知中找出“只有…才…”的条件

> Generated public Wiki page. Assessment answers are intentionally omitted.

- Course version: 2
- Lesson version: 1
- Track: hsk
- Framework / level: hsk-3.0 / HSK3–4
- Estimated time: 11 minutes

## Objective

读一则原创校园通知后，用“只有…才…”准确复述办理条件。

## Targets

只有…才…, 阅读提取, 条件, 校园通知

## Explanation

“只有 A，才 B”表示 A 是实现 B 的必要条件。读通知时先圈出条件，再找条件成立后能做的事；复述时不要把条件和结果说反。

## Examples

- **只有带学生证，才能进入阅览室。** — 带学生证是进入阅览室的必要条件。
- **只有在周五以前申请，才能参加活动。** — 时间限制属于条件，不是活动结果。

## Practice prompts

### Guided production

原创通知：进入语言实验室必须带学生证。请用“只有…才…”复述。

### Unaided retrieval

不看例子：周五以前报名的人可以参加比赛。请用“只有…才…”复述。

### Transfer

新通知：完成线上预约并带护照，才可以领取证明。请用“只有…才…”准确转告同学。
