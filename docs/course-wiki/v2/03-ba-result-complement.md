# 用把字句说明事情做完了

> Generated public Wiki page. Assessment answers are intentionally omitted.

- Course version: 2
- Lesson version: 2
- Track: daily-life
- Framework / level: GF0025-2021 / HSK3–4
- Estimated time: 11 minutes

## Objective

使用“把 + 事物 + 动词 + 结果 + 了”说明三个校园任务已经完成。

## Targets

把字句, 结果补语, 完, 好, 上

## Explanation

把字句把受影响的事物提前。表达已经完成的结果时，常用“把 + 事物 + 动词 + 结果 + 了”，例如“把作业写完了”。结果词紧跟动词，“了”放在结果之后。

## Examples

- **我把作业写完了。** — “完”紧跟“写”，“了”放在最后。
- **请把门关上。** — “上”说明门从开着变成关着。

## Practice prompts

### Guided production

根据提示说完整：I closed the door。使用“把”和结果词“上”。

### Unaided retrieval

不看例子：I finished writing the homework。请用把字句表达。

### Transfer

新场景：离开教室前，你已经把书放在桌子上了。请用把字句告诉同学。
