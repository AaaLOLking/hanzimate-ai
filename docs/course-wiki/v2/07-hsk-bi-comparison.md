# 用“比”比较两个校园选择

> Generated public Wiki page. Assessment answers are intentionally omitted.

- Course version: 2
- Lesson version: 1
- Track: hsk
- Framework / level: hsk-3.0 / HSK3
- Estimated time: 9 minutes

## Objective

使用“A 比 B + 形容词 + 程度”比较两个校园地点并给出选择。

## Targets

比字句, 更, 一点儿, 比较, 选择

## Explanation

“A 比 B + 形容词”说明 A 在某方面超过 B；需要表示差距时可在形容词后加“一点儿/多了”。“很”一般不直接放在比字句的形容词前。

## Examples

- **新图书馆比旧图书馆安静一点儿。** — 差距放在形容词“安静”之后。
- **东食堂比西食堂近多了。** — “多了”表示差距明显。

## Practice prompts

### Guided production

新图书馆更安静。请用“比”和“一点儿”比较新、旧图书馆。

### Unaided retrieval

不看例子：新宿舍离教室更远。请用“比”比较新宿舍和旧宿舍。

### Transfer

新场景：东食堂比西食堂近，但是西食堂便宜。请用两个比字句说明后选择一个。
