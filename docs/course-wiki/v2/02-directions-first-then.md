# 用“先…再…”说清校园路线

> Generated public Wiki page. Assessment answers are intentionally omitted.

- Course version: 2
- Lesson version: 2
- Track: daily-life
- Framework / level: hsk-3.0 / HSK2–3
- Estimated time: 8 minutes

## Objective

问路后用“先…再…”复述包含两个步骤的校园路线。

## Targets

先…再…, 问路, 路线, 顺序

## Explanation

“先…再…”把两个动作按时间顺序连接起来。先说第一步，再说第二步；两个动作都要清楚，听者才能照着路线走。

## Examples

- **先一直往前走，再向右转。** — “先”和“再”分别标记第一步和第二步。
- **先坐电梯到二楼，再往左走。** — 地点变化也可以放进两个连续步骤。

## Practice prompts

### Guided production

根据提示复述路线：first go straight, then turn right。

### Unaided retrieval

不看例子：first go upstairs, then turn left。请说一句完整路线。

### Transfer

新场景：同学问图书馆怎么走。请用“先…再…”给出两个合理步骤。
