# 用取件码和手机尾号取快递

> Generated public Wiki page. Assessment answers are intentionally omitted.

- Course version: 2
- Lesson version: 1
- Track: daily-life
- Framework / level: daily-life / HSK2–3
- Estimated time: 8 minutes

## Objective

在快递点说明来意，并准确报出一个取件码和手机尾号。

## Targets

取快递, 取件码, 手机尾号, 数字确认

## Explanation

取快递时先说“我来取快递”，再报取件码。对方需要核对电话时，可以说“手机尾号是……”。连续数字要一位一位读；对方没听清时，主动再说一遍。

## Examples

- **我来取快递，取件码是三八二一。** — 先说明来意，再逐位报号码。
- **我的手机尾号是六零九四。** — “尾号”表示号码最后几位。

## Practice prompts

### Guided production

你来取快递，取件码是 3821。请说一句完整的话。

### Unaided retrieval

不看例子：工作人员问手机最后四位，号码是 6094。请回答。

### Transfer

新场景：你要取快递，取件码是 5176，手机尾号是 2048。请一次说清两个号码。
