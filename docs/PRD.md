# HanziMate AI Web MVP PRD

> 状态：Week 8 错误定期复习与站内提醒已实现，验收见 week-08  
> 版本：0.8.0  
> 日期：2026-08-31  
> 产品范围：成人来华留学生、英文辅助界面、HSK 2–4

## 1. 产品目标

帮助学习者完成一个可重复的学习闭环：

1. 说或做；
2. 获得少量高价值反馈；
3. 确认反馈是否正确；
4. 把确认后的薄弱点写入长期档案；
5. 在合适时间复习；
6. 在后续真实对话中再次验证。

MVP 成功不以课件数量或模型数量衡量，而以相同错误是否减少、用户是否愿意持续开口衡量。

## 2. 目标用户

### 主用户

- 18 岁以上的来华留学生；
- 当前约 HSK 2–4；
- 能使用英文完成辅助说明；
- 每周愿意学习至少 3 次、每次 10–20 分钟；
- 同时具有考试或生活交流目标。

### 暂不支持

- 14 岁以下用户；
- HSK 7–9 高级备考；
- 教师班级管理；
- 官方考试成绩预测；
- 原生移动应用。

## 3. 核心价值假设

### H1：低压力实时开口

若用户能随时打断 AI、调节语速，并选择纠错强度，其有效开口分钟数会高于纯文本学习。

### H2：可解释长期记忆

若每条薄弱点都有原句、时间和用户确认，个性化会比仅保存聊天摘要更可信。

### H3：复习进入真实任务

若复习题能从旧错误变化为新场景，而不是机械重复原句，错误复现率会下降。

## 4. MVP 用户旅程

### 首次使用

注册 → 同意隐私选项 → 设置 Mission → 完成短诊断 → 获得能力概览 → 开始推荐对话。

### 日常使用

打开今日页 → 完成到期复习 → 继续课程或开始场景对话 → 查看会话报告 → 确认错误 → 获得下一步。

### 课程使用

选择课程 → 读取单一目标 → 学习例子 → 在右侧向 AI 提问 → 完成检索练习 → 写入学习证据。

## 5. 功能需求

### FR-01 建档与诊断

- 收集辅助语言、目标、期限、HSK 经历、每周时间和纠错偏好；
- 保存隐私同意的版本和时间；
- 生成听、说、读、写和词汇/语法的初始估计；
- 明确标识自评与系统证据的区别；
- 用户可以修改明显错误的判断。

### FR-02 工作区

- 左侧统一展示今日、对话、课程、错误回顾和学习档案；
- 每次课程或对话产生独立 workspace；
- workspace 显示进行中、待处理、待复习或已完成；
- 刷新或重新登录后恢复上次状态。

### FR-03 实时对话

- 浏览器使用 WebRTC 建立音频会话；
- 支持语音活动检测和用户打断；
- 同时显示用户与 AI 转写；
- 支持沉浸、教练和考试三种纠错模式；
- 支持慢速和正常语速；
- 当前 Qwen Realtime 单次默认与硬上限均为 8 分钟；更长训练未来通过分段会话和滚动摘要衔接；
- 结束后异步生成报告。

### FR-04 会话报告

- 输出场景完成度、表达亮点、最多 3 个重点问题和下一步；
- 每个问题包含原句、建议表达、简短解释、类型和置信度；
- 用户可以确认、驳回或编辑；
- 未确认的低置信度问题不得成为稳定薄弱点；
- 报告保留模型与 Skill 版本。

### FR-05 系统课程

- 首版 12 节：6 节校园/生活，6 节 HSK；
- Week 6 用 3 节校园中文短课验证完整学习闭环；Week 7 已通过课程 v2 扩展至 12 节；
- 每课只有一个可观察目标，预计 8–15 分钟；
- 包含必要知识、示例、即时练习、检索练习和真实任务；
- 右侧 AI 仅使用本课 Context Pack；
- 完成需要学习证据，不能仅以浏览到底判断；
- 已发布课程版本和课节内容不可原地修改，变更必须发布新版本。

### FR-06 错误簿

- 按发音、词汇、语法、汉字、听辨和语用分类；
- 展示来源、最近出现、次数、状态和下次复习；
- 重复错误聚合，但原始证据仍可展开；
- 用户可以删除记忆或停止提醒；
- 已驳回内容不参与后续教学。

### FR-07 定期复习

- 用户设置可学习日、提醒时间和目标保持率；
- FSRS 决定单项到期时间；
- 练习支持回忆、纠错、听辨、复述和角色扮演；
- 用户提交 Again、Hard、Good 或 Easy；
- 完成后立即显示下一次计划。

Week 8 实现说明：已确认错误进入天级 FSRS 或用户自定义间隔，支持文字产出、自评、学习日、时区与站内提醒。听辨和语音复习、邮件/短信推送及所有课程的自动复习卡尚未实现，具体边界见 [复习设计](review-scheduling.md)。

### FR-08 模型运维

- 按能力类别管理文本、实时语音、发音评测和向量模型；
- 记录每次调用的模型、耗时、Token、费用和状态；
- 密钥不下发浏览器，实时链路只使用短时凭证；
- 支持熔断、重试和降级；
- 用户首版只切换文本模型。

## 6. 非功能需求

### 性能

- Web 首屏在正常校园网络下 3 秒内可交互；
- WebRTC 建连成功率不低于 98%；
- VAD 结束到首个 AI 音频：P50 不高于 1.2 秒，P95 不高于 2.5 秒；
- 95% 的会话报告在结束后 60 秒内完成。

### 可靠性

- Provider 超时不造成 workspace 数据丢失；
- 异步任务至少一次投递，写入操作需幂等；
- 聚合画像可从证据事件重建；
- 模型结构化输出在持久化前通过 Schema 校验。

### 安全与隐私

- 所有用户查询强制带 user_id 范围；
- 原始录音默认不长期保存；
- 删除账户可清理个人数据和对象存储；
- 日志不记录 API Key、原始授权头或完整敏感语音；
- AI 记忆可查看、修正和删除。

### 可访问性

- 键盘可以访问主导航和操作；
- 麦克风状态不能只靠颜色表达；
- 转写与关键反馈满足基本对比度；
- 音频功能有文本降级路径。

## 7. 五条核心用户故事

### US-01 完成首次学习建档

作为一名刚到中国的 HSK 2 学习者，我希望告诉系统自己的目标和可用时间，以便获得不过难的第一周计划。

验收：

- Given 新用户已登录；
- When 完成 Mission、偏好和诊断；
- Then 系统创建 learner profile、展示证据来源，并推荐第一个对话场景；
- And 用户能修改辅助语言、语速和纠错方式。

### US-02 完成可打断实时对话

作为一名害怕开口的学习者，我希望 AI 可以被我自然打断，并在我表达时不过度纠错。

验收：

- Given 用户允许麦克风权限并选择教练模式；
- When 用户与 AI 对话至少 3 轮并在 AI 发言时插话；
- Then AI 停止当前音频并处理新输入；
- And 页面保留完整轮次和连接状态；
- And 每轮最多主动纠正一个重点。

### US-03 确认一次错误并在下次被使用

作为学习者，我希望知道系统为什么认为我有某个错误，并决定它是否应该被记住。

验收：

- Given 会话报告包含候选错误；
- When 用户展开证据并点击确认；
- Then 错误进入 confirmed 状态并创建复习项；
- And 下一次相关对话 Context Pack 可以召回该错误；
- But 不注入无关的全部聊天历史。

### US-04 边学课程边向 AI 提问

作为 HSK 3 备考者，我希望学习量词课时能随时提问，而 AI 不会偏离本课。

验收：

- Given 用户进入已发布的量词课程；
- When 用户询问本课示例或自己的新例句；
- Then AI 使用本课来源和用户相关错误回答；
- And 对不确定内容明确说明；
- And 完成练习后写入掌握证据并恢复进度。

### US-05 完成到期错误复习

作为经常忘记把字句的学习者，我希望系统在合适时间用新场景测试我，而不是只重复旧答案。

验收：

- Given 把字句复习项已经到期；
- When 用户从记忆完成一个新场景任务并评分；
- Then 系统保存 review log 并更新 FSRS 状态；
- And 显示下一次日期；
- And 后续会话以新的证据更新掌握度。

## 8. 发布门槛

封闭 Beta 前必须满足：

- 五条核心用户故事端到端通过；
- 任何跨用户数据泄漏测试为零；
- 结构化错误 Schema 通过率达到 99%；
- 20 个种子评测案例无阻断性错误；
- API Key 不出现在浏览器构建产物和日志；
- 用户可以删除一条记忆和整个账户；
- 记录每分钟实时对话的实际成本。

## 9. 未决但不阻塞 Week 1 的问题

- 中国内地公开上线前所需备案清单；
- 商业订阅按分钟、按月还是课程包计费。
