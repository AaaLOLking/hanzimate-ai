# 错误定期复习（Week 8）

## 用户流程

确认对话错误 → 自动加入复习 → 先写一句中文 → 查看示例和反馈 → 自评记忆情况 → 查看下一次日期。

刷新页面会恢复已经提交、尚未自评的作答。归档错误会停止复习和提醒，但不抹掉过去的记录。现在覆盖的是**已确认的错误**，不是所有已完成课程；听辨、录音与发音评分没有在本轮伪装为已完成。

## 时间安排

- 默认使用 [py-fsrs 6.3.2](https://pypi.org/project/fsrs/) 官方实现，目标保持率 0.90，可选择 0.85 / 0.90 / 0.95；接口接受 0.80–0.97。
- 采用天级产出练习：不启用分钟级学习/重学步骤，最大间隔 365 天，关闭随机扰动以支持准确重放。
- 自定义间隔为 1–60 天；选“忘记了”次日再练，其他自评使用用户间隔。FSRS 状态仍更新并保留，但不冒充实际安排日期。
- 可学习日采用周一=0 至周日=6，至少选一天。未来到期日落在非学习日时顺延，保留当地时刻。内部存 UTC，页面按用户选择的 IANA 时区显示。
- 修改偏好只影响之后的自评，不改写历史，也不隐藏已到期题。
- “轻量/均衡/更巩固”是复习密度选择，不是已测量的掌握度。

官方设计依据：[py-fsrs 说明及 API](https://github.com/open-spaced-repetition/py-fsrs)。

## 数据与可靠性

新增 `review_preferences`、`review_cards`、`review_attempts`、`review_logs`、`review_reminders` 五张表。迁移版本 `20260831_0006`。

- 一条错误记忆最多一张卡；启动时对旧的活跃记忆补建卡，原证据不变。
- 作答前的列表不包含答案、匹配规则或 FSRS 内部状态。
- 作答编号防止网络重试重复写入；每张卡每个版本只能有一个待自评作答。
- 自评通过卡片版本条件更新，状态与日志同一事务提交。重复相同自评返回原结果，冲突自评返回 409。
- 日志保留用户自评、作答引用、前后算法状态、完整参数、算法到期和最终安排，能够重放；没有覆盖历史记录的接口。
- 三类已有确定性错误（瓶装水量词、朋友量词、把字句结果）各有三种表面变式。其他错误提供明确标识的自评回顾，不冒充自动语义判分。
- 匹配结果不会覆盖用户自评，一次匹配不等于永久掌握。

## 提醒边界

用户主动开启。API 进程内每 60 秒检查：当地学习日、达到提醒时刻、有活跃到期卡，则写入一条站内提醒。按用户和当地日期去重，多进程竞争由唯一约束兜底。用户可关闭当日提醒或停用之后的提醒。

这不是 Codex 的任务提醒，也不是邮件/短信/系统推送。后端需要持续运行；停机期间不会发送，重启后只补当前日期符合条件的提醒，不补发过去多天。首页每 60 秒刷新，复习页可手动刷新。正式生产的独立任务进程、外部通知和大用户量分批扫描仍待后续建设。

## 接口

| 接口 | 用途 |
|---|---|
| GET /api/v1/reviews | 到期队列、未来安排、最近十条记录和当前提醒 |
| GET /api/v1/review-preferences | 查看个人节奏 |
| PUT /api/v1/review-preferences | 保存学习日、时区、间隔与提醒选择 |
| POST /api/v1/reviews/{card_id}/attempts | 提交一次产出，之后才返回参考表达 |
| POST /api/v1/review-attempts/{id}/rating | 用户自评并安排下一次 |
| PATCH /api/v1/review-reminders/{id}/dismiss | 关闭当日站内提醒 |

所有查询和写入沿用现有身份隔离。开发身份不是正式邮箱登录，生产上线前仍需完成可信身份接入。
